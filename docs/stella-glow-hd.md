# Stella Glow HD

An HD texture pack for Stella Glow: every texture upscaled 4x, with the UI, logos and anything with text in it redrawn by hand.

Version 0.9.0, by [simplysanatori](https://github.com/simplysanatori). Made on the USA version, title ID `0004000000173700`.

## What's in it

- Character sprites, portraits and battle portraits
- 3D characters, weapons and event CGs
- Menus, battle UI, dialogue boxes, title and chapter cards, staff roll
- About 14,700 textures, about 4.7 GB

Pair it with the [No Bloom](../games/stella-glow-usa/) patch. It fixes the ghosting and doubling on outlines around characters at internal resolutions above 1x, so it's practically required with this pack.

## How it was made

- Each texture was upscaled 4x with the 4x-AnimeSharp model, in overlapping tiles so no seams show.
- Transparency was upscaled separately, or redrawn by hand, to keep edges clean.
- The UI, logos and anything with text in it were redrawn by hand, in the game's font, Trebuchet MS.

## Install

- **Azahar for Frame:** use its in-app texture pack manager, **Mods** > **Textures** > **Download Packs**, and pick **Stella Glow HD**. See [Azahar for Frame](https://github.com/simplysanatori/AzaharFrame).
- **Azahar:** copy what's inside the folder in [the zip](https://drive.google.com/file/d/1XSi6l-QUmFrzYL4flQe6wZu1NGR859w_/view) into the emulator's `load/textures/0004000000173700/` folder and turn on **Use custom textures**.
